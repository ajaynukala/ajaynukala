
# Ajay Nukala 👋

### 💻 Full Stack Developer | Backend • Frontend • Cloud & DevOps

I build end-to-end web applications, from backend services and database design to responsive user interfaces and cloud deployments. I work with **Java, Spring Boot, Python, React, and REST APIs**, combining full-stack development with hands-on experience in cloud infrastructure and DevOps practices.

At PranavaEET Technologies, I contributed to applications across e-commerce, location-based services, and service platforms. At UNI IT Services CIC, I worked across the development lifecycle of a student learning platform, including frontend and backend integration, containerization, and cloud infrastructure.

I enjoy connecting the dots between frontend experiences, backend logic, databases, and deployment pipelines. I'm passionate about building maintainable software, solving real-world engineering problems, and continuously expanding my skills across full-stack development and cloud technologies.
